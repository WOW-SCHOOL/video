WOW SCHOOL — LIVE CLASSROOM / ДЕМО V1.0
====================================

ЧТО В АРХИВЕ
- index.php      — страницы входа и урока
- api.php        — PHP-синхронизация и сигналы WebRTC
- config.php     — демонстрационные учётные записи и задания
- style.css      — адаптивный дизайн
- app.js         — упражнения, синхронизация, видеосвязь

ДВЕ ТЕСТОВЫЕ УЧЁТНЫЕ ЗАПИСИ
Преподаватель:  teacher   / teacher123
Ученик:        student   / student123

КАК ЗАГРУЗИТЬ НА ХОСТИНГ
1. Требуется обычный веб-хостинг с PHP 8.1+ и HTTPS.
2. В FileZilla создай папку, например: /public_html/wow-demo/
3. Загрузи туда ВСЕ файлы из этого архива (index.php должен лежать прямо в wow-demo).
4. Открой https://ТВОЙ-ДОМЕН/wow-demo/
5. На компьютере зайди как teacher, на телефоне — как student.
   ВАЖНО: открывай именно опубликованный HTTPS-сайт на ОБОИХ устройствах,
   а не локальный файл или адрес localhost компьютера.
6. В уроке нажми «Включить видеосвязь» на обоих устройствах.
   Разреши доступ к камере и микрофону.
7. Преподаватель может переключать упражнения; ученик выполняет задания.
   Результаты синхронизируются через PHP примерно раз в 1,5 секунды.

ЕСЛИ НЕ УДАЛОСЬ СОЕДИНИТЬСЯ ПРЯМО ПО ВИДЕО
- Для WebRTC P2P используются публичные STUN-серверы. На одной Wi-Fi сети
  шанс успешного подключения выше; соединение из разных операторских сетей
  может требовать TURN-сервер (его в этой демонстрации нет).
- Преподаватель может выбрать внизу видеокарточки «Резерв Jitsi».
- Jitsi — сторонний сервис, здесь используется только для демонстрации.
  На публичном meet.jit.si для СОЗДАНИЯ видеокомнаты ведущему может
  потребоваться авторизация Google/GitHub/Facebook, второй участник
  сможет присоединиться как гость. Jitsi не гарантирует стабильную работу
  в стороннем iframe и не разрешён как постоянный хост для коммерческой
  интеграции: https://jitsi.org/api/

ВАЖНЫЕ ОГРАНИЧЕНИЯ
- Это ПРОТОТИП, не коммерческий сервис.
- Видео НЕ записывается; аудио НЕ сохраняется; ИИ-анализ не включён.
- Демо-логины и пароли общеизвестны, поэтому НЕ используй реальные
  персональные данные, ответы учеников или настоящее расписание.
- Никаких оплат/регистрации новых пользователей здесь нет.
- Данные ответов временно сохраняются в системной временной папке
  сервера PHP; хостинг может очистить их без предупреждения.
- Нельзя одновременно открыть две вкладки под одним и тем же аккаунтом:
  активной будет последняя вкладка в этой роли.
- Для реальной школы нужны полноценная авторизация и защита данных,
  база данных, устойчивый TURN / видеосервер, мониторинг и тестирование.
- Если PHP-хостинг запрещает запись в sys_get_temp_dir(), потребуется
  перенастроить storage_path() в api.php на доступную закрытую папку.
- Если сайт показывает исходный код PHP или предлагает скачать PHP-файл,
  PHP на хостинге не настроен: не публикуй такой сайт.

ФАЙЛЫ ZIP РАСПАКОВАТЬ И ЗАГРУЗИТЬ ВНУТРЬ /public_html/wow-demo/
Для Apache и Nginx никакие дополнительные правила URL не требуются.
